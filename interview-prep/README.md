# Java Backend Interview Preparation

## Purpose
A dedicated workspace for preparing for Java backend interviews at approximately the 5-year experience level.

## Files
- `AGENTS.md` — instructions for the interactive interview mentor.
- `Interview-Tracker.xlsx` — dashboard, topic tracker, question log and revision planner.

## How to use this workspace
1. Open this folder in Codex.
2. Choose a session mode: mock interview, guided learning, DSA practice, or code review.
3. Attempt questions before requesting explanations.
4. At the end of a practice session, review your mistakes and confirm the proposed tracker updates.
5. Use the Dashboard to identify weak subjects and the Revision Planner to revisit them.

## Session principles
- Prioritize understanding over memorization.
- Practise explaining answers aloud or in your own words.
- Record mistakes and hints honestly.
- Mark topics interview-ready only after demonstrating independent understanding.
- Keep coding exercises and interview coaching separate from production projects.
